# Contributing to A.B.I.R

First of all, thank you for taking the time to check out my portfolio and consider contributing! 🚀

This repository contains the source code for my personal portfolio, **A.B.I.R | Beyond Ordinary**. While the project is primarily maintained by me, suggestions, improvements, bug fixes, and constructive feedback are always welcome.

## 📌 Before You Contribute

Please keep the following in mind:

- This is a personal portfolio project, so changes should fit the overall design and purpose of the website.
- Keep the code clean, readable, and organized.
- Avoid introducing unnecessary dependencies.
- Make sure your changes work properly on both desktop and mobile screens.
- Do not add personal information, credentials, API keys, or other sensitive data.
- Please respect the existing visual identity and design system unless your contribution specifically proposes an improvement.

## 🐛 Reporting a Bug

Found something that isn't working correctly?

Please open an **Issue** and include:

1. A clear description of the problem.
2. Steps to reproduce it.
3. What you expected to happen.
4. What actually happened.
5. Your browser and operating system.
6. Screenshots or screen recordings, if applicable.

The more information you provide, the easier it is to investigate the issue.

## 💡 Suggesting an Improvement

Have an idea for improving the portfolio?

Open an **Issue** and explain:

- What you'd like to improve.
- Why you think it would be useful.
- How you think it could be implemented.
- Any examples or references that may help.

Design suggestions are especially welcome when they improve accessibility, responsiveness, usability, or performance.
